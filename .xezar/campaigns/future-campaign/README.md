# Future campaign

Reserved. This folder is **never** the live campaign: the leader elects the live one by sorting
digit-prefixed folder names under `.xezar/campaigns/` and taking the last, and this name has no
digit prefix.

Work aimed at a campaign that has not been opened yet is parked here. Opening a dated campaign is
the owner's decision, never a script's.

## How to open a campaign

Create `.xezar/campaigns/<YYYYMMDD>-<short-name>/` with the same seven file kinds as this folder,
move anything relevant out of here, and tell the leader.
