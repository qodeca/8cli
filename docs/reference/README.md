# Command reference

Use either spelling where an alias is shown: `workflow`/`wf`, `execution`/`exec`,
`credential`/`cred`, `variable`/`var`, `project`/`proj`, `datatable`/`dt`, and
`source-control`/`sc`.

- [Authentication and configuration](auth-config.md)
- [Workflows](workflows.md)
- [Executions and credentials](executions-credentials.md)
- [Tags, variables, projects and users](resources.md)
- [Folders](folders.md)
- [Data tables, audit and source control](operations.md)

All commands accept the [global options](../configuration.md). Error codes are `ERR_*` strings in
the stderr object; a command-specific `ERR_*` code identifies the failed operation.
